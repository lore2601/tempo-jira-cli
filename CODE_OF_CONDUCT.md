# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, discrimination and
personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer through a
[GitHub Security Advisory](https://github.com/lore2601/tempo-jira-cli/security/advisories/new)
or by contacting [@lore2601](https://github.com/lore2601). All reports are handled
confidentially.
